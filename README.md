
# PLP Python Week 4

This repository contains my Week 4 Python assignment on functions, parameters, return values, and default parameters.

* `welcome.py` - Defines a `welcome()` function that creates a greeting message and uses it for three different names.
* `toolbox.py` - Defines three functions: `double()`, `is_pass()`, and `greet()` and tests each function with different values.

The `greet()` function was the hardest to write because it uses a default parameter. I had to understand how Python uses `"Hello"` automatically when no greeting is provided, while allowing a different greeting when one is given.
